# source/ — 内容更新入口

把新版文件放到这个目录并提交（push）到 GitHub，网页会自动重新生成并发布。

支持的文件：
| 文件 | 作用 |
|------|------|
| `*.xlsx` | 卖点表格：更新 核心验收标准 / 细分类别 / 卖点参考 文案 |
| `*.zip` | 参考图压缩包：解压图片并追加为新图库分组 |
| `*.pdf` | 验收标准 PDF：提取内嵌图，按源页追加到图库 |

更新规则：
- 文案按表格行顺序与页面卖点一一对应，表格新增行会自动追加新卖点卡；
- 图片更新只新增分组，不会删除已有内容；
- 同名旧文件可直接替换。

也可以不碰 GitHub：把新版文件发给 Marvis，说一声「更新网站」即可。
